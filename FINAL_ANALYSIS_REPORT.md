## АНАЛИЗ АЛГОРИТМА EASCMINIMAP.LUA

### Корневая причина проблемы:

```lua
-- СТРОКИ 203-204: Вычисление размеров вместо координат
local width = math.abs(locRight - locLeft)   -- Ширина зоны
local height = math.abs(locTop - locBottom)  -- Высота зоны

-- СТРОКА 249: Неправильный формат вывода
file:write("[" .. areaID .. "] = { " .. data.height .. ", " .. data.width .. " }")
```

**Проблема:** Алгоритм берет данные из WorldMapArea.dbc.csv и вычисляет **габариты зоны**, а не **координаты центра** для позиционирования объектов на миникарте.

### Исходные данные из WorldMapArea.dbc.csv:
- `locLeft`, `locRight` - границы зоны по оси X  
- `locTop`, `locBottom` - границы зоны по оси Y
- `width = |locRight - locLeft|` - физическая ширина зоны
- `height = |locTop - locBottom|` - физическая высота зоны

## ИСПРАВЛЕНИЯ АЛГОРИТМА

### 1. Правильный расчет координат центра:
```lua
function calculate_minimap_center(area_data)
  local center_x = (area_data.locLeft + area_data.locRight) / 2
  local center_y = (area_data.locTop + area_data.locBottom) / 2
  
  -- Преобразование в систему координат миникарты
  local minimap_x = center_x * SCALE_FACTOR_X
  local minimap_y = center_y * SCALE_FACTOR_Y
  
  return { minimap_x, minimap_y }
end
```

### 2. Калибровка по эталонным зонам:
```lua
-- Использовать известные корректные координаты для калибровки
local reference_zones = {
  [4] = { working = {3350, 2234}, dbc_bounds = {locLeft, locRight, locTop, locBottom} }
}
```

### 3. Обработка инверсии координат:
```lua
-- Для зон с инверсией (Eastern Kingdoms)
if needs_coordinate_inversion(zone_id) then
  return { center_y * scale, center_x * scale }
end
```

## ЗАКЛЮЧЕНИЕ

**Генерированный файл eascminimap.lua содержит фундментальную ошибку в интерпретации данных.**

Алгоритм корректно извлекает данные из DBC файлов, но **неправильно их обрабатывает**, производя размеры зон вместо координат позиционирования. Это объясняет кардинальные различия с рабочими данными.

**Для исправления требуется:**
- Переписать функцию `calculate_minimap_dimensions` → `calculate_minimap_coordinates`
- Добавить калибровку по известным зонам
- Реализовать корректное преобразование систем координат

**Время исправления:** 2-4 часа разработки + тестирование
